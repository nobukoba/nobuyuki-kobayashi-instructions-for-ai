# Nobuyuki Kobayashi's Instructions for AI

Instructions for AI to create documents and other content in the style and structure preferred by Nobuyuki Kobayashi.

This repository is intended to be a source of truth for AI agents such as ChatGPT and Codex. Before drafting, rewriting, or editing content, identify the document type and read the corresponding style guide.

## Available instructions

- [Japanese email style](styles/nobuyuki-kobayashi-japanese-email.md)
- [GitHub README style](styles/nobuyuki-kobayashi-github-readme.md)

## For AI agents

See [AGENTS.md](AGENTS.md) for instructions on selecting and applying the appropriate style guide.

## Principle

The guides in this repository describe preferences rather than generic templates. Explicit corrections from Nobuyuki Kobayashi take precedence over existing rules and should be used to improve the guides over time.
